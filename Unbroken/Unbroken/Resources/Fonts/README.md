# Fonts

Drop the Montserrat font files provided separately by the team here (e.g. `Montserrat-Regular.ttf`, `Montserrat-Medium.ttf`, `Montserrat-SemiBold.ttf`, `Montserrat-Bold.ttf`).

The exact filenames must match the `UIAppFonts` array in [`Info.plist`](../Info.plist) and the PostScript names used in [`DesignSystem/Font+Brand.swift`](../../DesignSystem/Font+Brand.swift) — adjust both if the provided files use different names or weights.
